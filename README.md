# Loop explorer

Static parametric explorer for a satellite mechanically pumped fluid-loop thermal control system.

Glycol-water coolant, aluminum roll-bonded panels, rack cold plates, a canned pump, and a bellows accumulator. Round starting numbers, not a locked design close.

## Open locally

```bash
python3 -m http.server 8080
```

Then open [http://localhost:8080](http://localhost:8080).

Or open `index.html` directly in a browser. No build step.
